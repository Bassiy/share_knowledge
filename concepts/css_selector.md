# CSSセレクタ

## 概要
CSSルール（`セレクタ { 宣言ブロック }`）のうち、「どの要素にスタイルを当てるか」を指定する部分。

## 理解したこと

### CSSルールを構成する要素
CSSのルールは「セレクタ（誰に）」と「宣言ブロック（何を）」の2部構成になっている。

宣言ブロックの中には「プロパティ: 値;」という宣言が複数並ぶ。

```
#box.active   { transform: translateX(300px); }
└─セレクタ──┘   └───────宣言ブロック───────────┘
                └─────────宣言──────────┘
                └─プロパティ─┘ └────値────┘
```

| 用語 | 指すもの |
|---|---|
| ルール（ルールセット） | `セレクタ { 宣言ブロック }`全体のひとまとまり |
| セレクタ | 「誰に当てるか」を指定する部分 |
| 宣言ブロック | `{ }`で囲まれた、宣言が複数並ぶ部分 |
| 宣言 | `プロパティ: 値;`の1行（セミコロンまでが1つの宣言） |
| プロパティ | 宣言の左側。「何を変えるか」 |
| 値 | 宣言の右側。「どう変えるか」 |

セレクタが対象を絞り込み、宣言（プロパティ＋値）がその対象に適用するスタイルを決める。

---

### 複合セレクタと結合子の違い
セレクタをスペース無しで連結する書き方を複合セレクタ（compound selector）と呼び、「同じ要素が両方の条件を満たす」というAND条件を意味する。

スペースや`>`などの記号（結合子／combinator）を挟むと、「別の要素同士の関係」を表すようになる。

| 書き方 | 名前 | 意味 |
|---|---|---|
| `#box.active` | 複合セレクタ | 同じ要素が両方の条件を満たす（AND） |
| `#overlay.open #modal` | 子孫結合子（スペース） | `#overlay.open`の中にある`#modal`（何階層下でもよい） |
| `#overlay.open > #modal` | 子結合子（`>`） | `#overlay.open`の直接の子である`#modal`に限定 |

スペースの有無が「同じ要素への複数条件」か「別要素同士の関係」かを分ける境目になる。
