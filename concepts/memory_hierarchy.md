# メモリ階層

## 概要
コンピュータの記憶装置は速度と容量がトレードオフになった階層構造を持つ。CPUに近いほど高速・小容量、遠いほど低速・大容量。

## 理解したこと

### 階層と速度・容量のトレードオフ

```
レジスタ（CPU内）       超高速 / 数十〜数百バイト
         ↕
キャッシュ（L1/L2/L3）  高速   / 数百KB〜数MB
         ↕
RAM（主記憶装置）        中速   / 数GB
         ↕
補助記憶装置（SSD/HDD）  低速   / 数百GB〜数TB
```

キャッシュはCPU（レジスタ）とRAMの速度差を埋めるハードウェア的工夫。
参照型変数がアドレスだけ持つ設計（RAM上の話）とは別レイヤー。

---

### 主記憶装置の内部

| | 揮発性 | 役割 |
|---|---|---|
| RAM | あり（電源OFFで消える） | 実行中のプログラム・変数・データを保持 |
| ROM | なし（電源OFFでも残る） | 起動用プログラム（BIOS等） |

プログラムの変数や値が置かれるのはRAM。

---

## 関連概念
- computer_architecture（5大装置の全体構成。CPUと主記憶装置が処理の主戦場）
- types_and_variables（参照型変数はRAMのヒープ上アドレスを保持。値型はスタック上に直接保持）
