# メモリ階層

## 概要
コンピュータの記憶装置は速度と容量がトレードオフになった階層構造を持つ。CPUに近いほど高速・小容量、遠いほど低速・大容量。

## 理解したこと

### 5大装置と補助記憶装置

| 装置 | 役割 |
|---|---|
| 入力装置 | 外部からデータを受け取る |
| 出力装置 | 外部へデータを送り出す |
| 主記憶装置 | 実行中のデータ・命令を保持（RAM + ROM） |
| 制御装置（CPU内） | 他の装置への指示・命令の解読 |
| 演算装置（CPU内） | 純粋な計算処理 |
| 補助記憶装置 | 永続的なデータ保存 |

処理の主戦場は **主記憶装置（RAM）↔ CPU** の2つ。補助記憶装置はデータの永続化で絡む。

---

### CPUの内部構造

```
CPU
├─ 制御装置    : 他装置への指示・命令の解読
├─ 演算装置    : 加算・比較などの計算処理
└─ レジスタ    : 演算中の値の一時置き場（数十〜数百バイト）
```

演算装置が直接読み書きするのはレジスタ。RAMとは直接やり取りしない。

---

### 階層と速度・容量のトレードオフ

```
レジスタ（CPU内）       超高速 / 数十〜数百バイト
         ↕
キャッシュ（L1/L2/L3）  高速   / 数百KB〜数MB
         ↕
RAM（主記憶装置）        中速   / 数GB
         ↕
補助記憶装置（SSD/HDD）  低速   / 数百GB〜数TB
```

キャッシュはCPU（レジスタ）とRAMの速度差を埋めるハードウェア的工夫。
参照型変数がアドレスだけ持つ設計（RAM上の話）とは別レイヤー。

---

### 主記憶装置の内部

| | 揮発性 | 役割 |
|---|---|---|
| RAM | あり（電源OFFで消える） | 実行中のプログラム・変数・データを保持 |
| ROM | なし（電源OFFでも残る） | 起動用プログラム（BIOS等） |

プログラムの変数や値が置かれるのはRAM。
