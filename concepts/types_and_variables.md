# 型と変数

## 概要
値には型があり、変数はその型に合わせて用意する「入れ物の名前」。参照型では変数がメモリアドレスを保持し、値型では値を直接保持する。

## 理解したこと

### 型・変数・値の関係

型は「値に合わせて選ぶもの」。変数の型を先に決めるのではなく、入れる値の型に合わせて変数を定義する。

```csharp
string   text = "メモ";         // string型の値 → string型の変数
int      count = 42;            // int型の値    → int型の変数
Cat      obj   = new Cat();     // Cat型の値    → Cat型の変数
IAnimal  a     = new Cat();     // Cat型の値    → IAnimal型の変数（実装していれば）
```

構造はどれも同じ：「値の型に合わせた変数を用意して代入する」。

---

### 値型 vs 参照型

| | 変数が持つもの | 実データの場所 |
|---|---|---|
| 値型（int, bool, struct等） | 実データそのもの | スタック（変数の中） |
| 参照型（string, class, interface等） | メモリアドレス（参照） | ヒープ（別の場所） |

参照型の変数が「アドレスだけ」を持つのは、実データが重い可能性があるから。
必要な瞬間だけ実データを演算装置に引き上げる設計。

---

### クラス型・インターフェース型も同じ構造

インスタンスはRAM（ヒープ）上に生成された「値」。クラス型の変数を用意すればその値を代入できる。

```csharp
Cat     obj  = new Cat();    // Cat型変数 → Catインスタンスのアドレスを保持
IAnimal obj2 = new Cat();    // IAnimal型変数 → 同じCatインスタンスのアドレスを保持
```

変数の型が違っても、アドレスが指す先はどちらも同じCatインスタンス。
変数の型によって「見える窓口」が変わるだけ。

---

## 関連概念
