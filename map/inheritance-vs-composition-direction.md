# 継承とコンポジションはツリーの「方向」が違う

## 捉えるもの
同じクラスを扱いながら、継承は「型の抽象度」を、コンポジションは「構造の粒度」を表現する。
見た目は同じツリー構造でも、軸がまったく異なる。

## DOMを例に

### 2つのツリーの方向の違い

```
継承ツリー（下に行くほど型が増えて広がる）

Node
├── Element
│    └── HTMLDivElement
│    └── HTMLParagraphElement  ← 種類が増える
│    └── HTMLAnchorElement ...
├── Text
└── Attr ...
```

```
コンポジションツリー（下に行くほど粒度が小さくなる）

Document（全体）
  └─ html
       └─ body
            └─ p
                 └─ "Hello"（最小単位）← 細かくなる
```

---

### 軸の整理

| | 継承ツリー | コンポジションツリー |
|---|---|---|
| 表現するもの | 型の抽象度（is-a） | 構造の粒度（has-a） |
| 下に行くほど | 具体的な型が増える | 部品が小さくなる |
| 問いへの答え | 何者か | 何を持つか |

同じ「クラスのツリー」に見えて、軸が全く違う。
これが「継承ツリーとDOMツリーを混同しやすい」根本的な理由。
